# Boîtier ESP32 — charnière crochets + barre

## Ouverture / fermeture

- **Dans la boîte** : 2 crochets (berceaux) à l’arrière
- **Sur le couvercle** : une **barre** qui s’emboîte dans ces crochets  
→ le couvercle **reste accroché** et pivote pour ouvrir / fermer

Poignée à l’**avant** pour soulever.

## Couvercle

- **1 seul trou** : pour la diode, à **gauche**
- Pas d’autres trous

## Passe-fils

Sur le **même côté** que les crochets / accroche pot (**arrière**).

## Régénérer

`generer_stl.bat` ou `python generate_stl.py`
